## `./build-loop`

```text
┌────────────┐     ┌────────────┐     ┌──────────────┐     ┌───────────┐
│  DISCOVER  │ ──▶ │   BUILD    │ ──▶ │  UNDERSTAND  │ ──▶ │  REFINE   │
└────────────┘     └────────────┘     └──────────────┘     └───────────┘
    problem           prototype          debug + learn         simplify
```

- **Start with the problem.** The technology comes second.
- **Build small.** A working prototype teaches more than an enormous folder tree.
- **Break things.** Debugging is part of the curriculum, whether humanity likes it or not.
- **Understand the machinery.** Reuse good tools, but know what they are doing.
- **Ship useful work.** Clear and maintainable beats complicated for decoration.
